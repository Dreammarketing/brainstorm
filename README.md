# Brainstorm

Скіл для Claude Code, який **спершу прожарює твою ідею, а потім пише ТЗ**.

Ти кажеш «хочу CRM для мовної школи» або «хочу AI-агента, який відповідає клієнтам в Instagram». Агент не кидається писати код. Він допитує тебе раундами по 3–5 питань, докопується до суті, ловить суперечності, ріже зайве з першої версії. Коли все зрозуміло, він пише **ТЗ у Markdown**: сценарії, дані, інтеграції, план по етапах і готовий промпт, щоб одразу почати реалізацію.

Працює українською й російською: агент відповідає мовою, якою пишеш ти.

---

## Встановлення

### Варіант 1. Плагін (рекомендовано, оновлюється сам)

У Claude Code по черзі введи дві команди:

```
/plugin marketplace add Dreammarketing/brainstorm
```

```
/plugin install brainstorm@brainstorm
```

Перезапусти Claude Code.

### Варіант 2. Попроси Claude встановити

Встав у Claude Code одним повідомленням:

> Встанови скіл з https://github.com/Dreammarketing/brainstorm: скопіюй папку `skills/brainstorm` у `~/.claude/skills/brainstorm`. Потім перевір, що в ній є файли `SKILL.md` і `TZ-TEMPLATE.md`.

### Варіант 3. Руками (macOS / Linux)

```bash
git clone https://github.com/Dreammarketing/brainstorm.git /tmp/brainstorm && mkdir -p ~/.claude/skills && cp -R /tmp/brainstorm/skills/brainstorm ~/.claude/skills/
```

## Як користуватись

Відкрий Claude Code у папці, де будеш створювати проєкт, і напиши:

```
/brainstorm хочу CRM для мовної школи
```

Або просто «прожар мене, хочу зробити бота для запису клієнтів»: скіл підхопиться сам.

**Що буде далі:**

1. **Раунди питань.** 4–10 раундів по 3–5 питань. До кожного питання є рекомендація агента.
2. **Контрольна точка.** Агент переказує, як він усе зрозумів, і показує, що вирішив за тебе. Ти підтверджуєш або поправляєш.
3. **ТЗ.** Файл `docs/TZ-<назва>.md` (або `TZ-<назва>.md`, якщо проєкту ще немає).
4. **Що далі.** Почати етап 1 одразу, відкрити нову сесію з готовим промптом або віддати ТЗ розробнику.

**Як відповідати швидко:**

| Пишеш | Що це означає |
|---|---|
| `згоден` | Приймаю всі рекомендації раунду |
| `1а, 2 згоден, 3 — інакше: …` | Відповідь по пунктах |
| `не знаю` | Агент запропонує варіант і позначить як припущення |
| `на твій розсуд` | Агент вирішить сам і запише, що вирішив |
| `досить, пиши ТЗ` | Перейти до документа будь-коли |

**Займе 15–30 хвилин.** Це найкраще вкладені півгодини проєкту: вони економлять дні переробок.

## Що в ТЗ

Суть і проблема · Користувачі й ролі · Сценарії з критеріями «готово» · Функції першої версії і що відкладаємо · Дані й сутності · Інтеграції · AI-частина з прикладами діалогів · Інтерфейс · Доступи й безпека · Технічні рішення · Метрики й запуск · План по етапах · Ризики · Відкриті питання · Готовий промпт для старту реалізації

Рішення агента й припущення позначені окремо, щоб ти бачив, що вирішив сам, а що за тебе.

Повторний запуск `/brainstorm` у проєкті, де вже є ТЗ, доопрацьовує його й зберігає нову версію (`-v2`, `-v3`), старі не перезаписуються.
